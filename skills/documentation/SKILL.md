# Technical documentation

- Write from the reader's task: prerequisites, setup, operation, recovery, and verification.
- Keep commands copyable and paths accurate for the target platform.
- Describe current behavior, not intended future behavior.
- Remove obsolete feature claims when code is simplified.
- Explain security-sensitive storage and network behavior without exposing secrets.
- Verify names, flags, versions, and examples against the implementation.

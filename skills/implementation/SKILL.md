# Repository implementation

- Read repository instruction files and relevant build files before editing.
- Inspect current changes and treat unrelated work as user-owned.
- Make the narrowest coherent change that satisfies the request.
- Follow existing architecture unless the request requires a redesign.
- Never claim a build, test, migration, or runtime check passed unless it ran successfully.
- End with the outcome, changed areas, verification, and any real limitation.
